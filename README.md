# Planfin Dashboard เขตสุขภาพที่ 1

Dashboard วิเคราะห์แผนทางการเงิน (Planfin) เทียบผลการดำเนินงานจริงของโรงพยาบาล 103 แห่งในเขตสุขภาพที่ 1
ข้อมูลจากกองเศรษฐกิจสุขภาพฯ (M5317.mdb) และกลุ่มบริการ ปีงบประมาณ 2569

## หน้าจอ

1. **ภาพรวมผลประเมิน** ร้อยละ รพ. ที่ผ่านเกณฑ์ด้านรายได้ ค่าใช้จ่าย และทั้งสองด้าน
2. **รายโรงพยาบาล** แผนเทียบผลรายหมวด กดกางดูบัญชีย่อยและกราฟรายเดือน/สะสมได้
3. **หมวดรายได้** เลือกหมวดจาก dropdown ดูทุก รพ. ในกลุ่มเปรียบเทียบ พร้อม heatmap
4. **หมวดค่าใช้จ่าย** เหมือนแถบ 3 สำหรับฝั่งค่าใช้จ่าย

## วิธีคำนวณ

- เป้าหมายสะสม = แผนทั้งปี × จำนวนเดือน ÷ 12
- % คลาดเคลื่อน = (ผลจริงสะสม − เป้าหมายสะสม) ÷ เป้าหมายสะสม
- เกณฑ์เริ่มต้น: อยู่ในช่วง ±5% ถือว่าผ่าน (ปรับได้บนหน้า dashboard)
- ผลจริงมาจากงบทดลองสะสม (`DataIn`) จับคู่บัญชีกับหมวดตาม `AccCode`
- แผนมาจาก `hig_est_current` (256901 แผนต้นปี, 256902 แผนปรับกลางปี)
- หมวดที่ประเมินตาม flag ใน `PlanAdmin` ยอดรวมตามนิยาม P291/P292

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่ แล้ว upload ไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ **Settings > Pages**
3. ที่ Source เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
4. รอ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

`index.html` เป็นไฟล์เดียวที่มีข้อมูลฝังอยู่ในตัว เปิดในเบราว์เซอร์ได้ทันทีโดยไม่ต้องมี server

## อัปเดตข้อมูลเดือนใหม่

ต้องมี Python 3 และ `pip install pandas openpyxl` (ไม่ต้องใช้ Microsoft Access)

```bash
python tools/build.py path/to/M5317.mdb path/to/กลุ่มบริการ.xlsx
```

สคริปต์จะเขียนทับ `index.html` แล้ว commit/push ขึ้น GitHub ได้เลย

## โครงสร้างไฟล์

```
index.html          dashboard (มีข้อมูลฝังในไฟล์)
tools/build.py      สร้าง index.html จากไฟล์ .mdb + .xlsx
tools/jet.py        ตัวอ่านไฟล์ Access (.mdb) เขียนด้วย Python ล้วน
tools/template.html หน้าตา dashboard (ไม่มีข้อมูล)
```
